# Support process

Public contact: `support@korrespont.com` and `/support`.

1. Acknowledge security cases within one business day and ordinary cases within two business days.
2. Ask for browser, extension version, Windows version, GPU, website, exact error and support code.
3. Classify: security (P1), widespread outage (P2), reproducible defect (P3), compatibility/question (P4).
4. Treat any request for access, rectification, deletion, restriction, portability or objection as a data-subject request even if the user does not cite the GDPR. Record receipt time, scope, identity-check method, owner and the one-month deadline. Acknowledge within one business day.
5. Respond without undue delay and no later than one month after receipt. Any refusal must state reasons and complaint/judicial-remedy options.
6. Keep a minimal case record of dates, searches, decisions and completion. Escalate a missed or uncertain deadline as P1.
7. Close with the resolution, user-facing workaround and any follow-up release. Review recurring cases weekly.
