# Support

Public contact: `support@korrespont.com`

1. Acknowledge security cases within one business day, ordinary cases within two.
2. Ask for browser, extension version, GPU, website, exact error and support code.
3. Classify: security (P1), widespread outage (P2), reproducible defect (P3), compatibility (P4).
4. GDPR data-subject requests: record receipt time, scope, identity-check method, deadline. Acknowledge within one day.
5. Close with resolution, workaround and follow-up release.
